# Employee Registration System (Barcode + CSV + Live Dashboard)

A colorful web-based employee registration system that supports:
- Barcode scanning through one input field
- CSV master database upload (`EMP_NO`, `EMP_NAME`, `Gender`, optional `Status`)
- Real-time counts (total, male, female, registered, duplicates, inactive, mismatch)
- Live charts
- Timestamped scan history
- CSV export of scanned records
- Multi-station synchronization for 12 laptops using Supabase

## Files
- `index.html` - main page
- `styles.css` - colorful UI theme
- `app.js` - scanning, CSV parsing, counters, charts, cloud sync
- `sample_master.csv` - sample master data from your example

## Quick Start
1. Open `index.html` in the browser.
2. Upload your master CSV file.
3. Scan employee IDs using barcode reader (reader should send Enter after scan).

## Multi-Station Real-Time Setup (Supabase)
Use the same Supabase URL + Anon Key + Station-specific station ID on all 12 laptops.

Create these tables in Supabase SQL editor:

```sql
create table if not exists public.registrations (
  emp_no text primary key,
  emp_name text,
  gender text,
  master_status text,
  first_scanned_at timestamptz default now(),
  station_id text
);

create table if not exists public.scan_events (
  id bigint generated by default as identity primary key,
  emp_no text not null,
  emp_name text,
  gender text,
  status text,
  event_type text,
  station_id text,
  scanned_at timestamptz default now()
);
```

Enable Realtime for `scan_events` table in Supabase.

## Behavior
- First scan of an employee number => `registered`
- If scanned again from same/other laptop => `duplicate`
- If employee not in master CSV => `mismatch`
- If `Status` in CSV is inactive/disabled/terminated/retired => `inactive`

## Notes
- If cloud sync is not connected, the app works in local mode (single laptop scope).
- The app displays latest 500 scanned records for performance.
